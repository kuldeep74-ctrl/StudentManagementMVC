# Student Management System (ASP.NET Core MVC)

## 📖 Overview
A Student Management System built using ASP.NET Core MVC and Entity Framework Core. This project allows users to manage student records with full CRUD (Create, Read, Update, Delete) functionality.

## ✨ Features
- ➕ Add Student
- 📋 View Student List
- ✏️ Edit Student Details
- ❌ Delete Student
- 🏢 Department Management
- ✅ Model Validation
- 🗄️ SQL Server Database Integration

## 🛠️ Technologies Used
- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- HTML
- CSS
- Bootstrap

## 📂 Project Structure
```
StudentManagementMVC
│── Controllers
│── Models
│── Views
│── Data
│── Migrations
│── wwwroot
│── Program.cs
│── appsettings.json
```

## 🚀 How to Run

1. Clone the repository
2. Open the solution in Visual Studio
3. Update the SQL Server connection string in `appsettings.json`
4. Run database migrations
5. Press **F5** to start the application
